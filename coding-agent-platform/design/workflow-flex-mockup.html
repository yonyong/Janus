标准模式：与现状一致。区别仅在于澄清 / 用例节点右上出现「可跳过」能力——右键或 hover 出现「跳过此步」，跳过后节点变虚线、标「已跳过」，不影响后续。
轻量模式：主轴只有三格。「定义」节点下挂两个虚线 pill，任何时候点一下即补做对应阶段（就地展开，不改变主轴）。归档入口常驻右侧，不强制先完成前置。

③ 归档是唯一硬约束：缺依据时弱提示、不阻断

轻量需求（或跳过了用例的需求）点「归档验收」时的确认弹窗示意。
